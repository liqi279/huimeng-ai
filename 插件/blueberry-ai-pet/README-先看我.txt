Blueberry AI Pet v0.1 - Windows 桌面宠物原型

【启动】
1. 解压整个文件夹（不要只单独运行 BAT）。
2. 安装 Node.js LTS：https://nodejs.org/
3. 双击“启动桌宠.bat”。
4. 首次启动会自动下载 Electron 运行组件，需要联网。

【当前功能】
- 桌面悬浮窗口、置顶切换、隐藏、退出
- 使用你提供的蓝莓酱图片作为角色参考
- 点击互动、摸头反馈、表演动画（轻量 UI 动效）
- 独立聊天窗口
- 本地演示回复
- API Key / 模型 / Base URL 设置并保存在本机用户目录

【GPT API】
打开聊天窗口 -> 右上角“设置”：
- API Key：填写你有权使用的 API 密钥
- 模型名称：填写 API 账户实际可用的模型 ID
- Base URL：默认 https://api.openai.com/v1

注意：ChatGPT 中的 GPT-6 产品名称不保证对应一个可直接调用的 API 模型 ID。
请以你的 API 账户可用模型列表为准。若模型不可用，应用会显示接口错误。
API Key 保存在当前 Windows 用户的 Electron 应用数据目录，不要分享项目文件或密钥。

【重要说明】
这是可运行的桌面 MVP，不是完整 Live2D 成品：
- 当前角色展示使用原始参考图片，图片中原有文字和白色背景也会保留。
- 当前动画为界面级轻量动效，并非 Live2D 骨骼动画。
- 尚未实现浏览器扩展、Android/iOS 版本、语音、完整长期记忆。
下一阶段需要制作分层 PSD/绘制拆件，并在 Live2D Cubism 中绑定模型、物理效果和动作，再接入 Cubism SDK。

【如果双击后没有出现桌宠】
1. 确认 ZIP 已完整解压到普通文件夹，不要直接在压缩包预览中运行。
2. 双击“检查运行环境.bat”，确认能看到 Node 和 npm 版本。
3. 再双击“启动桌宠.bat”。
4. 如果失败，把自动生成的“启动日志.txt”发回 ChatGPT；日志会记录启动错误。
