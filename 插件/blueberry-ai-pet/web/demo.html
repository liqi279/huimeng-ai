右下角就是蓝莓酱：拖动移动位置，单击打招呼，双击打开聊天，右键打开菜单。

AI 默认为本地 Ollama（qwen3:4b）。启动 Ollama 前请设置 OLLAMA_ORIGINS=*；若是 HTTPS 页面，浏览器会拦截 http://localhost，请用 http 页面打开。

BlueberryPet.init({
  height: 280, right: 32, bottom: 24,
  api: { provider: 'ollama', baseUrl: 'http://localhost:11434', model: 'qwen3:4b' }
});
