BLUEBERRY AI PET v0.1.2 - WINDOWS FIX

1. Extract the ZIP completely.
2. Open the extracted folder. If you see another folder named Blueberry-AI-Pet,
   open it. The correct project folder contains package.json and main.js.
3. Double-click START-PET.bat (ASCII filename avoids Windows codepage issues).
4. First launch needs internet to download Electron dependencies.
5. If it fails, send startup-log.txt to ChatGPT.

Requirements: Windows 10/11 and Node.js LTS.
Node.js: https://nodejs.org/

This is an MVP using the supplied reference image. It is not yet a rigged
Live2D Cubism model. The configured model ID must be available to your API key.
