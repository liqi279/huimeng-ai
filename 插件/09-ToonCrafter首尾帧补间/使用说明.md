# ToonCrafter · 首尾关键帧补中间画

【用什么实现】官方仓库代码（PyTorch）或 ComfyUI 封装节点。

【原理】给两张线稿（首帧+尾帧），自动生成中间过渡帧，赛璐璐风友好。

【权重】HF 仓库需登录接受协议：https://hf-mirror.com/Doubao/ToonCrafter
下到本地后放到仓库 checkpoints/ 目录。

【怎么跑官方代码】
1. 解压源码.zip
2. pip install -r requirements.txt
3. python scripts/infer.py --img_path_0 首帧.png --img_path_1 尾帧.png
4. 输出中间帧序列，再用 RIFE（13号）补到顺滑帧率

【漫剧工作流】关键帧作画 → ToonCrafter 补间 → RIFE 插帧 → 上色。
