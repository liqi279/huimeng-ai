5 步上手 ComfyUI + Wan

  1. 装 ComfyUI

    从 GitHub clone，或下载官方包。Windows 用户直接解压双击 run_nvidia_gpu.bat 启动。

    git clone https://github.com/comfyanonymous/ComfyUI.git
  2. 下 Wan 模型

    从 ModelScope 或 HuggingFace 下载 Wan2.1 / Wan2.2 权重（.safetensors），放进 ComfyUI/models/diffusion_models/

    ModelScope 下载页 →
  3. 装 ComfyUI Manager

    插件管理器，一键装所有自定义节点（ComfyUI-Video-Matters、ComfyUI-VideoHelperSuite）。

    cd ComfyUI/custom_nodes/
    git clone https://github.com/ltdrdata/ComfyUI-Manager.git
  4. 导入 Wan 工作流

    拖入 .json 工作流文件 → ComfyUI 自动识别节点 → 点 Queue Prompt 跑第一张。

  5. 生成视频

    等待 2–10 分钟（依分辨率/步数/显卡），输出 MP4。搭好后每次生成零成本。

常见坑

显存不够

8G 显存跑 Wan14B 会 OOM，用 Wan2.2-2B 或 H3 轻量模型，或开 VAE 分片（GPU-only）。

WSL2 黑屏

WSL2 下需要额外配置 CUDA，建议直接 Windows 原生 + PyTorch GPU。

商用授权

Wan 系列 Apache 2.0 可商用。H3 需看快手授权说明。使用前自行确认。

时间成本

跑通 Wan2.2 工作流 ≈ 30 分钟。但一劳永逸，之后每个视频零成本。
